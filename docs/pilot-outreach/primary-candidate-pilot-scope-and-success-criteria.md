# Primary Candidate Pilot Scope & Success Criteria (Sprint 10G)

## Executive Summary
This document specifies the 4-week controlled pilot scope, learner cap, and success criteria for **Coral Bay Hospitality Ltd**.

---

## Controlled Pilot Scope

- **Learner Cap**: 50 learners
- **Duration**: 4-week active learning period
- **Courses**: ELH-01, ELH-02, ELH-03
- **Success Criteria**: >= 80% completion rate, >= 80% average quiz score, >= 50% survey response rate.
