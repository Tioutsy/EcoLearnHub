# Self-Service Client Flow Standard

## 1. Executive Summary
This document defines the autonomous end-to-end self-service journey for ELEVIO SKILLS for client organisations with up to 120 employees.

---

## 2. End-to-End Autonomous Journey

```
[Pricing Page] -> [Select Employee Band] -> [Sign Up / Register] 
     -> [Auto-create Organisation & Assign COMPANY_ADMIN] 
     -> [Company Setup Dashboard] -> [Add Employees] 
     -> [Assign Training] -> [Learner Access & First Course Completion]
```

### Employee Band Rules:
1. **Up to 25 employees**: MUR 3,000 / month (Max 25 seats)
2. **26–50 employees**: MUR 4,500 / month (Max 50 seats)
3. **51–80 employees**: MUR 5,000 / month (Max 80 seats)
4. **81–120 employees**: MUR 6,250 / month (Max 120 seats)
5. **Over 120 employees**: Tailored contact path (`/contact`)

---

## 3. Role & Permission Guarantee
- The user creating the organisation automatically becomes `COMPANY_ADMIN`.
- Invited employees default to `LEARNER` unless explicitly set to `MANAGER`.
- Platform Administrator approval is **never required** for self-service signups ≤120 seats.
