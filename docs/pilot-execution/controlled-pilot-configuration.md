# Controlled Pilot Configuration (Sprint 10C)

## Executive Summary
This document defines the parameters, candidate organisation slots, learner caps, course assignment rules, and privacy boundaries for the controlled external pilot.

---

## Approved Pilot Parameters

- **Candidate Companies**: 1 to 3 pilot organisations.
- **Learner Cap per Company**: 50 learners (unless explicitly expanded).
- **Pilot Duration**: 4 weeks of active learning access.
- **Supported Languages**: English and French.
- **Support Model**: Founder-led direct pilot support.
- **Commercial Billing**: Pilot trial; no automated billing in effect.
