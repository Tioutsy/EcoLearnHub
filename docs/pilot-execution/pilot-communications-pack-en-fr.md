# Pilot Communications Pack — English & French (Sprint 10E)

## Executive Summary
This pack provides polished English and French email communication templates across all 13 pilot lifecycle milestones.

---

## Template Summaries

1. **Initial Pilot Invitation**: Outreach to candidate company decision-maker.
2. **Participation Confirmation**: Confirmation of pilot scope and learner cap.
3. **Company Admin Welcome**: Portal access credentials for pilot administrator.
4. **Learner Invitation**: Bite-sized course invitation for enrolled employees.
5. **Learner Reminder**: Weekly reminder for active courses.
6. **Pilot Closing Notice**: 7-day advance notice before pilot access window concludes.
7. **Closure Review Meeting**: Invitation to present final company pilot report.
