# Pilot Company Onboarding Checklist (Sprint 10C)

## Executive Summary
This operational checklist outlines the required steps for internal setup, company administrator onboarding, learner onboarding, and manager onboarding.

---

## 1. Internal Preparation Checklist

- [x] Create company record in system with unique slug.
- [x] Set employee cap (e.g. 50 employees).
- [x] Set pilot start and end dates.
- [x] Assign initial pilot status (`preparing`).
- [x] Select target course assignment template.

---

## 2. Company Administrator Onboarding Checklist

- [x] Admin receives invitation link & authenticates.
- [x] Admin accepts `company_pilot_notice` (v1.0).
- [x] Admin verifies organisation profile & departments.
- [x] Admin adds employee roster or sends learner invitations.
- [x] Admin verifies reporting access at `/company/reports`.

---

## 3. Learner Onboarding Checklist

- [x] Learner receives invitation & signs in.
- [x] Learner selects preferred language (EN / FR).
- [x] Learner accepts `learner_privacy_notice` (v1.0).
- [x] Learner opens assigned courses from dashboard.
- [x] Learner completes lessons & passes end-of-course quiz (>= 80%).

---

## 4. Manager Onboarding Checklist

- [x] Manager receives invitation & signs in.
- [x] Manager accesses department progress view.
- [x] Manager reviews & comments on workplace action submissions.
