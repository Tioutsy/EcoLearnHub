# Pilot Proposal Revision Standard (Sprint 10J)

## Executive Summary
This document specifies proposal revision controls, version immutability (`v1` to `v2`), and field-level change summaries.

---

## Revision Rules

1. **Immutability of Issued Proposals**: Proposal `v1` remains immutable once issued.
2. **Version Incrementation**: Material scope revisions generate proposal `v2` with `proposalVersion: 2` and status `DRAFT`.
3. **Audit Immutability**: Previous proposal versions and change summaries are permanently preserved in `audit_logs`.
