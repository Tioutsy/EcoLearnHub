# Live Support and Incident Standard (Sprint 10N)

## Executive Summary
This document specifies live support procedures, severity classification (SEV-1 to SEV-4), and escalation pathways.

---

## 1. Incident Severity Classification

| Severity Level | Response SLA | Target Workflow | Escalation |
| :--- | :--- | :--- | :--- |
| `SEV-1` | 1 Hour | Security incident, tenant data exposure, platform down | Platform Admin |
| `SEV-2` | 4 Hours | Onboarding, auth, course completion, report export blocked | Support Lead |
| `SEV-3` | 24 Hours | Significant feature defect with available workaround | Dev Team |
| `SEV-4` | 72 Hours | Minor visual, wording, or usability issue | Backlog |
