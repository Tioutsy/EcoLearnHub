# External Validation Classification Standard (Sprint 10D)

## Executive Summary
This standard defines the 9-stage external validation framework required to track platform validation from internal technical testing to commercial customer onboarding.

---

## 9-Stage External Validation Hierarchy

| Stage Identifier | Stage Name | Required Evidence | System Status | Commercial Gate |
| :--- | :--- | :--- | :--- | :---: |
| **Stage 0** | Internal Technical Validation | Automated tests, test fixtures, unit/integration passes | `test` / `demo` | Blocked |
| **Stage 1** | Prospect Identified | Company profile identified for outreach | `candidate` | Blocked |
| **Stage 2** | Prospect Contacted | Verifiable initial outreach logged | `contacted` | Blocked |
| **Stage 3** | Pilot Discussion Active | Meeting or written discussion recorded | `discussion` | Blocked |
| **Stage 4** | Pilot Participation Confirmed | Signed/written agreement, authorised contacts, dates, learner cap | `participation_confirmed` | **CONDITIONAL GO** |
| **Stage 5** | Pilot Launched | Real organisation created, admin active, learners invited, >1 course started | `active` | **CONDITIONAL GO** |
| **Stage 6** | Pilot Completed | Pilot duration ended, completion metrics recorded, survey feedback collected | `completed` | **CONDITIONAL GO** |
| **Stage 7** | Commercial Interest Confirmed | Named decision-maker, recorded continuation interest, pricing presented | `commercial_discussion` | **CONDITIONAL GO** |
| **Stage 8** | Commercial Customer Confirmed | Signed contract, purchase order, billing details, commercial onboarding authorised | `converted` | **GO** |
