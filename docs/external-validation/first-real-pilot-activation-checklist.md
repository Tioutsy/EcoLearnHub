# First Real Pilot Activation Checklist (Sprint 10D)

## Executive Summary
This operational checklist must be executed prior to onboarding the first confirmed external pilot organisation.

---

## Activation Checklist

- [x] Written participation confirmation received from authorised officer.
- [x] Authorised primary contact and data privacy contact identified.
- [x] Pilot company created in database with `recordEnvironment = "external_pilot"` and `isTestRecord = false`.
- [x] Employee cap configured (e.g. 50 employees).
- [x] Pilot start date and end date set in database.
- [x] Pilot stage set to `participation_confirmed` (Stage 4).
- [x] Company Administrator invited & `company_pilot_notice` delivered upon login.
- [x] Roster loaded and learner invitations issued.
- [x] Support channel (`/support`) active and monitored.
