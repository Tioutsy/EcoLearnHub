# Pilot Learner Intake Guidance — English & French (Sprint 10H)

## Executive Summary
This document provides bilingual learner intake instructions and CSV column validation rules.

---

## Column Specifications

1. `first_name`: Required (String)
2. `last_name`: Required (String)
3. `email`: Required (Valid corporate email format)
4. `department`: Optional (e.g. Operations, HR, Facilities)
5. `language`: Required (`en` or `fr`)
