# Acceptance Authority Verification Standard (Sprint 10H)

## Executive Summary
This document specifies representative authority verification standards for candidate organisations.

---

## Authority Verification Rules

1. **Title Alignment**: Representative holds managerial or executive title (Group Sustainability Manager, HR Director).
2. **Corporate Domain**: Representative communicates via corporate domain email (`@coralbay.mu`).
3. **Written Consent**: Acceptance must reference company approval and exact proposal version.
4. **Authority Status Flag**: Backend flag `authorityVerified = true` required for conversion.
