# EcoLearnHub Course Visual Media Governance

## Overview
This document specifies rules for selecting, storing, and referencing visual assets in EcoLearnHub courses.

---

## 1. Permitted Media Sources
1. Original EcoLearnHub diagrams or vectors.
2. Verified public-domain or CC-BY open-licensed photography.
3. Official environmental pictograms (e.g. recycling symbols, energy stars, ISO signs).
4. Stock photography from licensed repositories.

---

## 2. Accessibility & Performance Requirements
- **Descriptive Alt Text**: Mandatory for all visual media.
- **Text Equivalent**: Required for complex charts or diagrams.
- **Mobile Readability**: Images must scale gracefully down to 320px viewport without clipping or font degradation.
- **No Reliance on Color Alone**: Visual identification must use clear labels or shapes in addition to color.
