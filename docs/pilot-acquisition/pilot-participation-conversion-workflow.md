# Pilot Participation Conversion Workflow (Sprint 10F)

## Executive Summary
This document specifies the 10-step conversion workflow connecting accepted proposals to Sprint 10E participation evidence intake.

---

## 10-Step Conversion Process

1. Candidate accepts issued proposal (`v1` / `v2`).
2. Acceptance evidence reference recorded (`acceptanceRef`).
3. Authorised representative confirmed.
4. Participation evidence status set to `ACCEPTED`.
5. Scope reconciled with accepted proposal payload.
6. Learner count and course IDs locked.
7. Data handling and privacy notice acknowledged.
8. Company administrator invited.
9. Internal activation handover pack generated.
10. Readiness gate evaluated for guarded activation.
