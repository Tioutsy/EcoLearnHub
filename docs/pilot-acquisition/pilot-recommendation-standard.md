# Pilot Recommendation Standard (Sprint 10F)

## Executive Summary
This standard establishes curated course pathway recommendations for pilot proposals to ensure micro-learning focus without overwhelming workplace learners.

---

## Recommendation Guidelines

- **Curated Pathways**: Recommend 3 to 4 bite-sized modules per pilot (e.g. `ELH-01` Sustainability Foundations + `ELH-02` Waste Sorting + `ELH-03` Energy Efficiency).
- **Catalogue Overload Prohibition**: Avoid assigning all 29 courses in a single pilot proposal.
- **Language Delivery**: Default to bilingual English and French presentation.
