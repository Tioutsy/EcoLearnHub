# Quiz Answer-Position Audit Document (Sprint 10J)

## Executive Summary
This document records the global correct-answer position distribution audit across all 29 courses before and after Sprint 10J rebalancing.

---

## 1. Acceptance Criteria & Thresholds
- **Position 1 Maximum**: <= 30.0% of all correct answers.
- **Global Position Maximum**: <= 35.0% for any single position.
- **Global Position Minimum**: >= 20.0% for all positions 1 through 4.
- **Course Concentration Maximum**: No course with >= 8 questions may place > 50% of answers in one position.
- **Consecutive Position Maximum**: <= 3 consecutive questions with the same correct answer position.
